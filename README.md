# Control Peso Pro 🏋️‍♂️

App definitiva para control de peso, nutrición y entrenamiento con IA - hecha para ti.

### 🚀 Qué hace
- **Peso Objetivo:** pones "Quiero pesar 70kg" y te calcula déficit, kcal/día, fecha estimada y 3 escenarios (solo dieta / solo entreno / mixto)
- **Comidas:** añade alimentos, favoritos, biblioteca Mercadona, foto con IA, y ahora **borrar con 🗑️** y vaciar día
- **Medidas:** % grasa Navy, cintura, cadera, fotos de progreso
- **Entrenamientos:** Manual + Xiaomi Band 8 real + **Fuerza con bandas/peso corporal**
- **Coach IA Fuerza:** chat que responde a "hago 6 flexiones ¿cuántas series?" "peso hombro 5kg" "rutina 20min bandas" usando tu test inicial
- **Biofeedback:** sueño, agua, fibra, pasos Xiaomi, NEAT, racha 🔥, adherencia, retos, modo viaje
- **Guardado:** todo se guarda en tu móvil con botón 💾 Guardar mi perfil

### 📱 Cómo usarla
1. Abre `index.html` en el navegador
2. En móvil: Compartir → Añadir a pantalla de inicio → ya la tienes como app
3. Pon tus datos reales en Perfil y dale a Guardar

### 🌐 Subir a GitHub Pages
1. Crea repo nuevo en GitHub
2. Sube `index.html` y `README.md`
3. Settings → Pages → Deploy from branch main/root
4. Tu link: https://tuusuario.github.io/control-peso-pro/

Hecho con IA para control total sin suscripciones.
